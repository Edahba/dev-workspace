# Portfolio Personnel - Dev Workspace

## Description
Portfolio web développé avec *React.js* et *Vite* dans le cadre de la formation Développement Digital, option Full Stack, à la CMC Laâyoune.

Ce portfolio a pour objectif de présenter mon profil, mon parcours académique, mes compétences et mes différents projets.

## Contenu du Portfolio
Le site est composé de trois parties principales :

### 1. Information
- Présentation de mon profil.
- Parcours académique.
- Compétences techniques.

### 2. Projects
Présentation de mes réalisations :
- *Site Web Statique – CMC Laâyoune* : présentation d'un site web statique.
- *Page Vitrine E-commerce* : affichage de produits avec images, prix et descriptions (React / Bootstrap).
- *Biblio - Story Book* : projet de bibliothèque de livres.

### 3. Contact
Un formulaire permettant aux visiteurs de saisir leurs coordonnées et d'envoyer leurs messages.

## Navigation
La navigation entre les différentes pages est assurée par *React Router DOM*, permettant une expérience utilisateur fluide.

## Stack Technique
- React.js
- JavaScript
- HTML5 / CSS3
- Bootstrap 5
- React Router DOM

## Installation et Lancement

### 1. Cloner le projet
git clone https://github.com/Edahba/dev-workspace.git

### 2. Accéder au dossier
cd dev-workspace

### 3. Installer les dépendances
npm install

### 4. Lancer le serveur de développement
npm run dev

### 5. Ouvrir dans le navigateur
http://localhost:5173
